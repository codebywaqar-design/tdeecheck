# TDEE Check (tdeecheck.com)

A focused TDEE and nutrition calculator site. Astro static build, no backend, every calculator runs in the browser.

## What is inside
- Homepage TDEE calculator (Mifflin-St Jeor, optional Katch-McArdle body fat mode, imperial and metric units)
- BMR, Calorie, Macro and BMI calculators under /calculators/
- TDEE weight loss landing page
- Blog, About (reviewed by Waqar, Dietitian), Contact, Privacy, Terms, Medical Disclaimer

## Develop
npm install
npm run dev

## Build
npm run build
Static output lands in dist/, ready for Vercel or any static host.
